# DbGate 社区版 MCP 半残，tools/call 调不通

### Summary
`DbGate 7.2.6` 社区版 `MCP` 需设 `MCP_TOKEN` 才启用（否则 `/mcp` 报 `403 DBGM-00245`）；启用后 `tools/list` 正常（11 个全是读/元数据工具，无 query/execute），但任何 `tools/call` 都报 `DBGM-00355`（`getAuthProviderFromReq` 返回 null，社区版无 `STORAGE_DATABASE` 撑不起权限上下文）。结论：社区版 `MCP` 实际不可用，`AI` 查库仍走各直连 `MCP`（如 `sqlite-dev-ro`），勿为 `MCP` 改架构。

### Details
- endpoint 为 `http://<host>:3000/mcp`（Streamable HTTP，`Bearer` 鉴权）。
- 开关：`MCP_TOKEN` env（`enabled:!!token`，见 `bundle.js` `readMcpConfig`）；另有 `MCP_PUBLIC_URL`/`MCP_AUTH_MODES`/`MCP_ROLE_ID`（默认 `-4`），社区版用不上。
- 11 个工具：`list_connections/list_databases/list_objects/get_table_info/get_table_data/list_tables/list_collections/list_views/list_procedures/list_functions/list_triggers`——连自由 `SQL` 查询都没有，更无写。
- 已回滚：`dbgate` compose 去掉 `MCP_TOKEN` 并重建，面板 `200` 正常。

### Suggested Action
以后再有人提“用 DbGate MCP 代替直连”，直接引用本条：除非升级 `Team Premium`（`STORAGE_DATABASE` + 细粒度权限），否则免谈。
